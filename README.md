🎮 Simple Web Game

A fun and interactive browser-based game built using HTML, CSS, and JavaScript.
This project demonstrates basic game logic, user interaction, and dynamic UI updates using JavaScript.

The game is designed to run directly in the browser, making it lightweight and easy to play without installing anything.

✨ Features

🎮 Interactive gameplay

⚡ Smooth and simple game logic

🖥️ Runs directly in the browser

🎨 Clean and lightweight UI

📱 Responsive layout for different screen sizes

🛠️ Tech Stack

HTML5 – Structure of the game

CSS3 – Styling and layout

JavaScript – Game logic and interactions
